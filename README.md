# 🦁 Wildlife Animal Website

A simple and visually appealing **Wildlife Animal Website** built using **HTML and CSS**.  
The website contains three main pages: **Home, Gallery, and About Us**.

The project focuses on showcasing wildlife, promoting wildlife conservation, and presenting different animals through an image gallery.

---

## 🌿 Website Preview

The website includes a wildlife-themed design with animal photography, a navigation bar, information sections, a gallery, and a wildlife video.
 https://wildlifewebsite.vercel.app/
### 🏠 Home Page
The home page introduces visitors to wildlife animals and provides information about the importance of wildlife and biodiversity.

### 🖼️ Gallery Page
The gallery displays different wildlife animals, including:

- 🦌 Deer
- 🐒 Monkey
- 🦊 Fox
- 🐘 Elephant
- 🐆 Leopard
- 🦏 Rhino
- 🦓 Zebra
- 🐇 Rabbit
- 🐒 Ecuador/Monkey

### 🌍 About Us Page
The About Us page focuses on wildlife conservation and explains why protecting wildlife and their natural habitats is important.

It also includes a wildlife video section.
